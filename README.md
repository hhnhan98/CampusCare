# CampusCare

CampusCare là ứng dụng mô phỏng hỗ trợ sinh viên HUTECH gửi và theo dõi yêu cầu sửa chữa cơ sở vật chất trong khuôn viên trường.

> Đây là đồ án phục vụ học tập, không phải ứng dụng chính thức của HUTECH.

## Công nghệ

### Mobile App
- Flutter
- Dart
- Material 3
- Provider
- Dio
- go_router

### Backend
- Node.js
- Express.js
- Prisma ORM
- PostgreSQL
- JWT

## Cấu trúc dự án

- `campuscare_app`: ứng dụng Flutter
- `campuscare_backend`: REST API
- `docs`: tài liệu dự án

## Phạm vi MVP

- Sinh viên đăng nhập, tạo và theo dõi yêu cầu sửa chữa.
- Quản lý xem yêu cầu, cập nhật trạng thái và ghi chú xử lý.
- Ảnh được lưu local tại backend.
- Dữ liệu được lưu trong PostgreSQL.
